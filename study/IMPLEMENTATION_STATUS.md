## Deliberate Boundaries

There is no generic numeric-token firewall on arbitrary generated financial prose because the model is not allowed to write that prose. Templates own financial sentences, and verified source excerpts retain their page provenance. A quote appearing in a source proves faithful quotation, not independent truth; supporting-source discrepancies remain visible.

The agent investigates evidence for review; it does not vary the report's required numerical inventory. Direct API calls and a small retrieval interface are used instead of an orchestration framework or vector database. No Terraform deployment, unrestricted financial overrides, universal PDF/OCR adapter, or cryptographic reviewer identity was added. Supporting-document matching and prior-NAV checks have explicit parsing limits. Chart readings need human confirmation; repeated live success is evidence, not a universal provider-determinism guarantee.
